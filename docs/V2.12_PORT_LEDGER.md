# v2.12 port ledger

Survey of 2026-11-12. Upstream `upstream/main` at `99e780e2` (ProxyShard
v2.1.5, 2026-11-11); the previous port (`docs/V2.3_PORT_LEDGER.md`) stopped at
`9174751` (v2.1.0). The fork's launcher diverged after v2.1.0 (own Team, fleet
custody, UI), so nothing below is a plain cherry-pick: each item is
re-implemented on the fork's code.

## Why this port was urgent

The engine archives live in upstream's public bucket (`PUB_BASE`), not in this
repo. On 2026-11-10 the bucket started serving the Chromium 157.0.8103.50 build
(etag `57a2ea08…-26` for Windows) while the fork's `runtime.json` still named
156.0.8078.48. A fresh install or a forced reinstall therefore extracted a 157
engine under profiles migrated to 156, and the stored etag never matched the
manifest again. Pointing `runtime.json` at the build the bucket serves fixes it.
